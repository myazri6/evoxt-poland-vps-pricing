## 波兰 VPS 的价格真相：华沙不加价，贵在附加项

### 五家的华沙节点和西欧同价，这一点已经核验

Vultr 的华沙机房跟它其他机房同一套价，1 核 1GB 是 $5；OVHcloud 订购目录里 WAW 没有附加费；Azure 波兰中部的 B1s 按 $0.012 一小时计，跟西欧同价；UpCloud 价格页写的是 Global price，各机房一个价；Scaleway 华沙的价格页和巴黎一样。

所以不用因为“波兰”两个字先假设贵一档。真正拉开差距的是配置策略和附加项，不是地理位置。

### 三个容易做错预算的地方

Scaleway 的 DEV1-S 列表价 €6.55 一个月。价格页原文写明，列表价含出站流量和 IPv6 地址，不含硬盘和附带的公网 IPv4。IPv4 每小时 €0.005，约 €3.65 一个月，加上去就是 €10.20，硬盘还要按容量另算。最低那档 STARDUST1-S 是 €0.43 一个月，加 IPv4 约 €4.08，同样不含硬盘，而且只在 WAW-2 有货，别的区开不了。

Azure 官方原话是 “Disk storage is billed separately from virtual machines”，B1s 的小时价里没有盘。按 $0.012 一小时乘 730 小时大约 $8.76 一个月，这是不含硬盘的数。

OVHcloud 官网上的大字 “From €3.81 ex. VAT/month” 是预付 12 个月的折算月价。月付 €4.49，一次付一年 €45.72，月付一年 €53.88，两种买法差 €8.16，预付便宜约 15%。第一个月掏的是 €45.72，不是 €3.81。这笔钱值不值，取决于你能不能确定这台机器开满一年。

OVHcloud 波兰官网用的是兹罗提：VPS-1 净价 16,32 PLN、含税 20,07 PLN 一个月，配置是 2 核 4GB、40GB NVMe、500Mbps、不限流量、每日备份。兹罗提含税价和第三方汇总的欧元不含税价是两套口径，别把两个数字加在一起算总账。

### 关机之后还扣不扣费，各家规则相反

Vultr 关机照扣，只有删机才停费。有人开一台试了试，点了个关机就去忙别的，两个月后登录发现余额少了一截，问题就出在这里。Scaleway 反过来，关机就停机器费。这两家的规则完全相反，按自己的使用习惯选：机器常年开机，差别不大；经常开开关关做测试，Scaleway 的计费方式更省。

其余几家的关机规则在公开页面上没有完整写清，下单页或者条款里确认一遍再开机。
